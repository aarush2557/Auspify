## 📌 Overview

This project demonstrates an end-to-end **Data Cleaning & Preprocessing** workflow using **Python** and **Pandas** on a Netflix dataset.

It was completed as **Task 1 (Easy)** during my **Data Scientist Internship at Auspify Technologies**.

The notebook focuses on transforming raw data into a clean, structured, and analysis-ready dataset by applying industry-standard data preprocessing techniques.

# 🎯 Project Objective

The objective of this project is to prepare a raw Netflix dataset for Exploratory Data Analysis (EDA) and Machine Learning by:

- Cleaning inconsistent data
- Handling missing values
- Removing duplicate records
- Standardizing data formats
- Engineering useful features
- Optimizing data types
- Producing a clean dataset ready for further analysis
