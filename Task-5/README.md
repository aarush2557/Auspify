# 📖 Overview

This project presents a complete Machine Learning Classification Pipeline developed during my Data Scientist Internship at **Auspify Technologies**.

The notebook performs data preprocessing, feature engineering, model training, evaluation, comparison, visualization, prediction, and model deployment preparation using Scikit-Learn.

The project is designed following industry-standard Machine Learning practices and is suitable for portfolio, GitHub, Kaggle, and LinkedIn showcase.

---

# 🎯 Project Objective

Build an end-to-end Machine Learning Classification Model capable of automatically classifying Netflix content using available dataset features.

---

# ❓ Problem Statement

Netflix contains a large collection of Movies and TV Shows.

The objective is to build a classification model capable of learning patterns from the available dataset and accurately predicting the selected target category.

---

# 📂 Dataset Information

- Dataset Name: clean_netflix_dataset.csv
- Dataset Type: Structured CSV
- Records: Automatically Detected
- Features: Dynamic Detection
- Missing Values: Automatically Handled
