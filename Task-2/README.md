# 📌 Overview

This project performs **Exploratory Data Analysis (EDA)** on a cleaned Netflix dataset to uncover meaningful trends, patterns, relationships, and business insights using Python.

The notebook demonstrates professional data analysis practices including:

- Dataset exploration
- Statistical analysis

# 🎯 Project Objective

The objective of this project is to analyze Netflix content and answer questions such as:

- What type of content dominates Netflix?
- Which countries produce the most titles?
- Which genres are most popular?
- How has Netflix grown over time?
- What are the most common maturity ratings?
- Which directors and actors appear most frequently?
- What business insights can be derived from the data?
