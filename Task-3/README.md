# 📌 Overview

This project presents a **Content-Based Recommendation System** built using the **Netflix Movies & TV Shows Dataset**.

The recommendation engine analyzes textual metadata including movie descriptions, genres, cast, directors, ratings, and other attributes to recommend similar content.

Instead of relying on user ratings, this project uses **Natural Language Processing (NLP)** techniques to measure content similarity.

This project was completed as **Task 3 (Medium)** during my **Data Scientist Internship at Auspify Technologies**.

---

# 🎯 Project Objective

Develop a scalable and production-quality **Content-Based Recommendation Engine** capable of recommending Netflix titles based on textual similarity using machine learning techniques.

---

# ❓ Problem Statement

Modern streaming platforms contain thousands of titles, making content discovery difficult.

The objective of this project is to recommend relevant movies or TV shows by analyzing content features instead of collaborative user behavior.

# 🧠 Recommendation Approach

This project follows a **Content-Based Filtering** approach.

Unlike collaborative filtering, recommendations are generated by comparing movie metadata rather than user interactions.

---

# ⚙️ Feature Engineering

The recommendation engine combines multiple metadata fields into a single feature representation.

Features include:

- 🎭 Genre
- 📝 Description
- 🎬 Director
- 👥 Cast
- 🌍 Country
- ⭐ Rating
- 🎥 Type
- ⏳ Duration
- 📅 Release Year

---

# 🧹 Text Preprocessing

The following preprocessing techniques were applied:

- Convert text to lowercase
- Remove punctuation
- Remove numbers
- Remove special characters
- Remove extra whitespace
- Generate a clean text corpus

---

# 📖 TF-IDF Vectorization

The cleaned text corpus is transformed into numerical vectors using **TF-IDF Vectorization**.

Advantages:

- Captures important keywords
- Reduces the impact of common words
- Produces sparse feature vectors
- Suitable for NLP recommendation systems

---

# 📐 Cosine Similarity

Cosine Similarity is used to calculate similarity between TF-IDF vectors.

Similarity Score Range

| Score | Meaning |
|--------|----------|
| 1.0 | Identical Content |
| 0.8+ | Highly Similar |
| 0.5+ | Moderately Similar |
| 0 | Completely Different |
