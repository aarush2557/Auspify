# 🚀 Project Overview

This project is the **Sixth and Final Internship Task** completed during my **Data Scientist Internship at Auspify Technologies**.

The objective of this project was to transform raw Netflix content data into meaningful business insights using:

- Data Analytics
- Exploratory Data Analysis
- Business Intelligence
- Interactive Dashboard Development
- Machine Learning Segmentation
- Data Storytelling


The project analyzes Netflix's global content library and provides strategic recommendations for content expansion, market opportunities, and audience-focused decisions.


---

# 🎯 Business Problem

Streaming platforms generate huge amounts of content data. Understanding this data helps businesses answer:

- Which countries produce the most successful content?
- Which genres dominate the platform?
- How has Netflix content grown over time?
- What type of content should Netflix invest in?
- How can content libraries be segmented?


This project builds a data-driven solution to answer these questions.
